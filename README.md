# Wealth Taxes in Europe

This repository contains a self-contained static website in `index.html`.

## Publish with GitHub Pages

1. In the repository on GitHub, open **Settings → Pages**.
2. Set **Build and deployment → Source** to **GitHub Actions**.
3. Push a change to `main`, or run **Deploy GitHub Pages** from the **Actions** tab.
4. Wait for the workflow to finish. The site will be available at
   <https://fengvonriva.github.io/Wealth-Tax-Europe/>.

The workflow publishes only `index.html`; it does not require a framework,
package installation, or external runtime dependencies. Subsequent pushes to
`main` publish updates automatically.
